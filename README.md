### 📚 Sistema Escuela (PHP + MySQL + Bootstrap)

Este proyecto es una aplicación web básica desarrollada con PHP, MySQL y Bootstrap, que permite visualizar datos de alumnos almacenados en una base de datos.

🚀 Características
Página principal (index.html) con interfaz moderna
Página de visualización (mostrar.php) que:
Se conecta a una base de datos MySQL
Consulta registros de una tabla
Muestra los datos en una tabla estilizada con Bootstrap
Navegación entre páginas
Diseño responsive utilizando Bootstrap
